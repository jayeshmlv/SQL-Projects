# Workforce Salary Analysis & Insights | SQL Project

## Overview

This SQL project analyzes workforce salary data to uncover trends in salaries, job roles, experience levels, company locations, and remote work. The goal is to answer business questions and generate insights that support hiring and compensation decisions.

---

## Business Objective

- Analyze salary trends across roles and experience levels.
- Identify high-paying job roles and countries.
- Evaluate remote work adoption.
- Generate actionable business insights using SQL.

---

## Tools & Skills

- MySQL
- SQL
- Joins
- CTEs
- Window Functions
- Aggregate Functions
- Data Analysis

---

## Key Insights

- Salaries increase with experience level.
- AI/ML roles offer the highest average salaries.
- Remote work has grown significantly over the years.
- Certain countries consistently provide higher compensation.
- Entry-level data roles show promising salary growth.

---

## Business Recommendations

- Offer competitive salaries for high-demand technical roles.
- Expand remote work opportunities to attract global talent.
- Benchmark compensation against leading markets.
- Invest in employee upskilling and career development.
