# SQL Projects Portfolio

This repository contains SQL projects focused on solving real-world business problems through data analysis. Using SQL, I explored datasets, answered business questions, and generated actionable insights to support data-driven decision-making.

---

## Projects Included

### 1. Workforce Salary Analysis & Insights

Analyzed workforce salary data to identify salary trends across job roles, experience levels, company locations, and remote work. The project provides insights to support compensation planning, workforce management, and hiring decisions.

**Key Skills:** Workforce Analytics, Salary Analysis, Trend Analysis, SQL Querying

---

### 2. Customer Behavior Analysis in Online Food Delivery

Analyzed customer purchasing behavior, revenue patterns, and the impact of Gold Membership on customer engagement using SQL. The project focuses on customer segmentation, revenue optimization, and loyalty program analysis.

**Key Skills:** Customer Analytics, Revenue Analysis, Customer Segmentation, Business Insights
